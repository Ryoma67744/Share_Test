Share_Test オフライン版 — 最初にお読みください
Windows 10/11（64ビット x64）用 / 説明書更新: 2026-10-09

【最初の3ステップ】
1. Share_Test_Offline.zip を右クリックして「すべて展開」します。
2. 展開先の START_OFFLINE.bat をダブルクリックします。
3. ブラウザーで http://127.0.0.1:8765/ が開いたら利用できます。
   自動で開かない場合はEdgeまたはChromeで上記アドレスを開いてください。

初回もインターネット不要。追加ソフトのインストールや管理者権限も不要です。
BATだけを取り出さず、同梱フォルダーをすべて一緒に保管してください。
利用中は黒い起動ウィンドウを開いたままにします。
終了は処理完了後にブラウザーを閉じ、起動ウィンドウで Ctrl+C です。

【最初に行う操作】
元ファイルから: 「+ 新規プロジェクト」で名前・実験日時・サンプル種・装置を入力
→ Create → + Section → + HE/IF または + MSI でデータを登録。
データ用ZIPから: 初回は新規プロジェクトを作成してビューアを開きます。
→ Import ZIP で、Export ZIPで作成したプロジェクトZIPを選択。
アプリ配布用のShare_Test_Offline.zipはImport ZIPに入れません。

【詳しい操作】
HOW_TO_USE.html をダブルクリックしてください。ネット不要で読めます。
基本操作、ROI、MRM、バックアップ、別PCへの移行、困ったときの対処を掲載しています。
アプリのHelpでも同じ操作説明を読めます。

【必ず覚えておくこと】
・データは使用したブラウザー内です。毎回同じブラウザー・プロファイルを使います。
・プライベート/シークレットウィンドウを使わず、サイトデータを消さないでください。
・各プロジェクトは Export ZIP、MRM全体は MRM バックアップで別々に保存します。
・MRM 復元は現在のMRM全体の置き換えです。復元前にもバックアップを保存します。
・アプリフォルダーのコピーだけでは作業データをバックアップできません。
・クラウド共有・同期・複数人の同時編集は使用しません。

起動に失敗した場合は表示されたエラー文を控え、HOW_TO_USE.htmlの
「困ったとき」を確認して配布元に連絡してください。
