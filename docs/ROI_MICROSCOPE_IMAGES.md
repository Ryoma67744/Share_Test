# ROIに対応する顕微鏡写真（v2026-09-24.5）

微小なROIに、撮り直した高倍率のHE・蛍光顕微鏡写真を新規登録できます。ROI LISTの行を右クリックするか、写真ボタンを押すと比較ウィンドウが開きます。

## 操作

1. ROI LISTから対象ROIの比較ウィンドウを開きます。複数切片に描かれたROIでは、写真を対応付ける切片を選びます。
2. 「画像を追加」で新しい写真を選びます。複数の写真を登録でき、後から追加・差し替え・削除・代表画像の指定ができます。
3. 左側で写真を選び、名称、HE／IF等の種類、倍率、撮影日、メモを編集して保存します。写真の拡大・移動、全体表示、100%表示もできます。
4. 右側で対応するMSI化合物を選びます。初期表示はROI周辺で、全体表示との切り替えができます。周辺余白はMSIの2・4・8・16セルから選び、初期値は4セルです。
5. ウィンドウは移動・サイズ変更できます。比較画面の操作で、主画面の選択化合物・切片・ズームは変更されません。

写真はROI名や色ではなく、ROIと切片の識別情報に結び付けます。ROIの改名や表示色の変更後も対応は保たれます。切片全体のHEレイヤーに写真を置く必要はありません。

## 画像と表示の仕様

| 項目 | 動作 |
| --- | --- |
| 入力形式 | PNG、JPEG、単一画像の標準TIFF |
| 上限 | 1ファイル500 MiB、長辺16,384 px、67,108,864画素 |
| 原本 | 登録時のファイルをそのまま保存。表示用の処理で原本を上書きしません |
| TIFF | 表示は既存デコーダーによる8bit RGB。多ページ・階層TIFF・BigTIFFは対象視野を単一画像に書き出して登録します |
| 写真のスケールバー | 校正値（µm/px）が入力された場合に表示。40×等の倍率だけでは計算しません |
| MSI | 全体と拡大で同じ強度範囲・カラーマップを使用。拡大時は補間を使わず画素を表示します |
| MSIのROI輪郭 | 拡大率によらない細い輪郭で表示。小さいROIを塗りつぶしません |
| 位置の対応 | MSIの測定座標、画素中心、回転・反転・物理ピッチを使って切り出します。顕微鏡写真との自動位置合わせは行いません |

比較画面を開いた時点の表示設定を保持します。主画面で表示条件を変更して比較に反映したい場合は、比較画面を開き直してください。

写真登録時のROI形状と測定ソースも記録します。形状変更後には注意表示を出し、別の測定ソースのMSIは比較対象にできません。測定データを差し替えた場合は、写真との対応を確認して再登録してください。

## 保存・共有

- 写真原本と登録情報はローカルに保存し、保存失敗は画面に表示します。別プロジェクトへの移動時は写真の保存処理の完了を待ちます。
- Export ZIPには写真原本と対応情報を含めます。Import ZIPやサーバーからローカルへの取り込みでは、切片IDを変換して対応を復元します。原本欠落時は成功扱いにしません。
- Publish to shareで写真もアップロードします。写真原本のアップロードが失敗した場合は、公開処理を中止します。
- 共有画面では写真とMSIを閲覧できます。写真の編集はローカルのマスタープロジェクトが対象です。共同編集ROIへの写真登録には対応していません。
- 共有写真の配信は、既存の`atlases`ストレージの公開URLを利用します。
- ローカルプロジェクト削除では、他プロジェクトが参照する原本を残します。写真削除・差し替え後の未参照ローカル原本は既存の未参照データ整理処理の対象になります。
- 管理画面からのサーバープロジェクト削除では、既存の`unlock_project_master`／`get_project_doc`で登録写真の保存先を取得してから削除します。読み取りや認証ができなければ、プロジェクト削除を開始しません。SQL変更は不要です。
- サーバー削除で整理するのは取得時点の登録原本です。過去の差し替え履歴の原本や、削除と別端末からの公開が同時に起きた場合の未参照原本を、自動で全件整理する機能は含みません。

## 検証

`tests/roi_media_*_regression.js`で登録・差し替え・保存失敗時の復元、非同期操作、ソース照合、2×2セル相当のROI、画素中心と変換、ZIPの原本保持とID変換、公開・共有・削除を検証します。画素検証には実Canvasを、操作検証にはDOMと保存先のテスト用実装を使用しています。

実ブラウザーでの操作と実際のSupabaseへの書き込みは、この変更の自動テストでは実行していません。
