# ZIP の復元・原本・来歴

[English](ARCHIVE_COMPATIBILITY.en.md)

Export ZIP は、開始時点で登録されている画像、数値ソース、ROI 写真、登録情報をまとめます。HE/IF を含め必要な原本が一つでも読めなければ、不足した切片・ファイルを表示して停止します。部分的な ZIP を成功としてダウンロードしません。作成中に登録内容や ROI、位置合わせが変わった場合も、もう一度実行してください。表示用 PNG は原本とは別の派生物です。

Import ZIP は、参照されるファイルと切片・ROI の対応を先に点検します。復元画面に来歴別の件数を表示し、新しい独立プロジェクトとして保存します。既存のプロジェクトを上書きしません。処理中の「中断」は次の確認点で停止します。容量不足等で失敗した場合も、その復元が新しく作った一時ファイルだけを回収します。

## 対応する旧形式

- 初期 v1 の `project.json` と `sections/.../atlas.json` 形式に対応します。分子ごとのコピーが同じ内容なら一つの原本として復元します。同じ source ID に異なる内容の保存版がある場合は、それぞれを別ソースとして保持します。
- 異なる保存版を分けた場合、旧 ROI・位置合わせがどの版に対応するかを推測しません。元の polygon と登録情報は保持しますが、対応を確認できない旧 ROI 定量は実行しません。
- 後期 v1、v2 の RAW/Parquet 原本、現在の全形式の原本も復元します。ZIP 内に宣言されたファイルが欠けている場合は、オンライン版でもオフライン版でも停止します。

## 来歴表示の意味

| 表示 | 意味 |
|---|---|
| 原本登録 | この対応版で利用者が登録したファイルを保持しています。機器から出力後に外部で加工されていないことまでは保証しません。 |
| 旧保存ファイル | 旧 ZIP に収録されたファイルを保持しています。旧 XLSX exporter は ROI 列を追記する場合があったため、登録前の bytes と同一とは認定しません。 |
| 旧 CSV 参考値 | 登録時ファイルがなく、旧 exporter の CSV を使用しています。 |
| 来歴未確認 | これまで保存された情報から由来を確認できません。保存し直すだけでは確認済みになりません。 |

旧 CSV には、元の空欄がゼロとして保存されている場合があります。ゼロを空欄へ推測補正したり、失われた行を追加したりしません。背景除去の `drop` 設定は保持しますが、元の行数がなければ実際の除去件数は分かりません。`flag` は背景フラグを付けた設定です。これらの値から計算した統計は、旧 CSV に基づく参考値です。

来歴はレイヤーごとに保存し、再 ZIP・再 import でも引き継ぎます。新しい `originalSeries` や統計計算バージョンが付いても、旧 CSV が登録時原本に戻るわけではありません。PPT は同じ MSI 詳細ページに短い品質注記を表示します。Project information ページや非表示の測定条件を追加する機能ではありません。CE/CV の出力権限と選択は従来通りです。

原本を別途お持ちの場合は、旧 CSV のゼロを書き換えず、そのファイルを別ソースとして登録して確認してください。自動的な TXT/XLSX 原本の再対応付けは行いません。数値が似ているだけでは同じ測定とは判定できません。

## 保存の保護と限界

復元・出力中の原本は作業用の記録で保護します。Web Locks に対応したブラウザでは、再起動時に終了した復元の記録を回収し、別タブで進行中の処理は触りません。Web Locks がない環境では、生存中か判断できない記録を安全のため保持します。既存プロジェクトや復旧用コピーが参照する原本は削除しません。

ZIP の完全性は、今回の開始時点で登録された参照に対する保証です。昔の exporter が ZIP に含めなかったファイル、空欄の区別、失われた行を、この機能だけで復元することはできません。旧アプリで再保存すると来歴情報が失われる場合があるため、元の ZIP を保管してください。
