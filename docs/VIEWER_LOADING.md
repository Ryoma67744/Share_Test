# 段階的な画像表示とDESI背景の再利用

プロジェクトを開くと、切片の枠と操作部品を先に準備し、画面内で必要な画像から読み込みます。大きな非表示HE/IFや、画面外の切片の読み込み完了は待ちません。スクロールや分子選択に応じて読み込み対象が変わります。

共有URLから開く場合も、登録情報を先に読み込み、必要な原本だけを取得します。同じ原本を複数のMRMが使う場合は取得中の処理を共有します。未取得の原本は未登録やゼロ信号として扱わず、取得失敗は再試行できます。Previewも実際に表示される切片から読み込みます。比較画面ですべての切片が見えている場合は、その切片すべてが読込対象になります。

ROIは画像と並行して取得します。準備中・取得失敗を「ROIなし」とは扱いません。ROIの編集・集計・ROI限定Range・ROIを含む出力は準備完了を待ちます。原本取得やキャッシュ更新だけでは、プロジェクトを編集したり自動公開したりしません。

DESIの合成TIC背景は選択した画像の初期表示後に準備します。TICだけを表示する保存設定は維持され、別の画像を勝手に表示しません。表示をOFFにした背景が、遅れて完了した処理によってONへ戻ることもありません。

## 数値と比較範囲

原本の数値読取、ROI統計、比画像とその統計、ROI限定Rangeの集計は、画面操作と別のWorkerで実行します。Parquetは従来どおり必要な列を部分取得し、その後の座標・ラスタ・統計処理をWorkerで行います。解析結果、MRM照合、Rangeの計算式や集計順序は変更しません。

表示と解析は同じ数値Workerの待ち行列と原本キャッシュを使います。解析用キャッシュは128 MiB、画面側の原本スナップショットは64 MiB・24件までです。破棄された結果は必要時に再計算します。選択切替やプロジェクト変更で不要になった処理は中止し、古い結果を反映しません。Workerが失敗した場合に大きな処理を画面側で自動的にやり直すことはせず、再試行できる失敗として扱います。

Sameの共通スケールは表示対象として選択した切片全体から求めます。画面のスクロール位置で比較範囲は変わりません。保存済み統計が不足しているプロジェクトでは、必要な分子の統計を準備してから比較画像を表示します。Individualや上限を指定した手動Rangeは、他切片の共通上限を待ちません。

TICの計算は従来どおり、各分子をそのベイク範囲で8bitへ変換して画素ごとに平均し、最大平均値で正規化する表示用背景です。元データの生強度合計やROI定量値を置き換えるものではありません。パーサー、未測定画素、丸め、格子と位置合わせの規約は維持します。

## キャッシュの保存

生成した背景は原本・プロジェクト保存とは別のブラウザー内データベースに保存します。容量は64 MiB、件数は128件を上限とし、使われていない背景から破棄します。削除されても原本から再生成できます。保存容量不足やキャッシュ破損が通常のMSI閲覧を失敗させることはありません。

再利用は元ファイル、対象分子の順序、読取設定、ベイク設定、参照寸法、計算方式の版が一致する場合に限ります。カラーマップ、透明度、ズーム、ROI編集はTIC入力を変えません。内容を特定できない旧式のリモート参照は、再訪をまたぐ永続キャッシュの対象外です。既存の保存済みTICは従来どおり読み込みます。

背景のキャッシュ保存だけでは、プロジェクトの編集・公開予約・公開revision更新を発生させません。途中で失敗・キャンセルした生成結果を完成済みの背景として保存しません。

## 読み込みと出力

主画像、サムネイル、TICは同じ優先制御を利用し、ユーザーが選択した画像を優先します。同時に処理する画像数を制限し、巨大Parquetの初期化は元ファイル単位で共有します。プロジェクトや原本を切り替えた場合、古い処理の完了結果は現在の画面へ適用しません。

解析・PPT・ZIP等の明示的な出力要求は、画面外や非表示のデータも必要に応じて読み込みます。未読み込みを画像欠損として扱いません。原本の保存、取り込みの完全性、共有読み込みの保持記録は既存の仕様を使います。

サーバーだけにあるプロジェクトを最初に取り込む際の原本転送は、今回の段階的表示とは別の処理です。取り込み後の表示は改善しますが、全原本の転送を途中で完了扱いにはしません。
